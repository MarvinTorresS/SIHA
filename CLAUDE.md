## Design Skills — Which One to Use

Two design skills are installed in this project:

- **Impeccable** (`.claude/skills/impeccable/`) — the active one. `PRODUCT.md` and
  `DESIGN.md` were generated by it, from real project context and a scan of the
  actual codebase. Use `/impeccable <command>` for design work by default.
- **redesign-existing-projects** (taste-skill, `.agents/skills/redesign-existing-projects/`)
  — installed but intentionally NOT active. Its defaults conflict with decisions
  already made in this project: it discourages Inter/Lucide and pushes fonts like
  Geist/Outfit/Satoshi and icon sets like Phosphor/Radix instead of this project's
  Sora + lucide-react. Do not apply it automatically.

If a change introduces a font other than Sora, or replaces lucide-react icons with
something else, without being explicitly asked, that is a sign taste-skill's rules
leaked in instead of Impeccable's — flag it and revert to the Sora/lucide-react
convention.
